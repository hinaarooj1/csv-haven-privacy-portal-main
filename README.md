
# Cameleon Renov

## Vue d'ensemble du projet

Site web officiel de Cameleon Renov, spécialiste en solutions d'isolation écologiques et économiques.

## Technologies utilisées

Ce projet est construit avec :

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Installation locale

Pour exécuter ce projet localement :

```sh
# Étape 1 : Clonez le dépôt.
git clone <VOTRE_URL_GIT>

# Étape 2 : Naviguez vers le répertoire du projet.
cd <NOM_DU_PROJET>

# Étape 3 : Installez les dépendances nécessaires.
npm i

# Étape 4 : Démarrez le serveur de développement.
npm run dev
```

## Déploiement

Pour déployer cette application, construisez la version de production et déployez sur votre hébergeur préféré :

```sh
npm run build
```

Les fichiers générés se trouveront dans le dossier `dist`.

## Personnalisation

Le site peut être facilement personnalisé en modifiant les fichiers dans le dossier `src` :

- `src/components/` - Composants réutilisables
- `src/pages/` - Pages principales du site
- `src/hooks/` - Hooks personnalisés
- `src/lib/` - Fonctions utilitaires
